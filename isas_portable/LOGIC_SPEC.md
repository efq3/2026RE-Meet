# ISAS 수신·RMS·온도 표시 로직

기준: GitHub `a63b534`의 센서 JSON 형식과 PC 수신·계산 코드. 아래는 현재 구현된 계산을 설명한다.

## 계산 위치와 데이터 흐름

- Raspberry Pi: 4개 암대 가속도·온도를 읽어 한 줄 JSON으로 출력하고 TCP로 전송한다.
- PC `server.py`: 원본/수신 시각을 저장하고 `logic.Detector`에 패킷을 넣는다.
- PC `logic.py`: 최근 센서창과 비행 상태로 지표를 계산한다.
- `web/monitor.js`: 서버 SSE의 계산 결과를 받아 숫자와 그래프를 표시한다.

원본 수신·저장률은 입력률을 따르며, 특징값·웹 전송 주기는 계산 시간에 0.2초 대기가 더해져 약 5 Hz이다. 수집률은 센서 timestamp로 계산한다.

## 평균 제거 3축 RMS

각 암대 i의 최근 2초 구간에서 축별 평균을 빼고 제곱합의 평균에 제곱근을 취한다.

```text
mean_i = mean(acceleration_i, per axis)
RMS_i = sqrt(mean((X-mean_X)^2 + (Y-mean_Y)^2 + (Z-mean_Z)^2))
relative_RMS_i = RMS_i - median(RMS_1, RMS_2, RMS_3, RMS_4)
```

단위는 m/s²이다. 상수 오프셋과 일정한 중력 성분은 평균 제거로 상쇄되지만, 기동 중 변화하는 중력의 센서축 투영·기체 가속도·회전 운동이 제거되는 것은 아니다. 대역통과 필터는 아직 적용되지 않았다.

## 데이터 유효성

- 채널별 중복·역순 timestamp를 제외한다.
- 12개 이상의 표본과 설정창 길이의 80% 이상인 시간 범위가 필요하다.
- 최근 수신 후 3초가 지나면 해당 채널을 데이터 없음으로 표시한다.
- 큰 공백은 간격 중앙값의 4배 또는 50 ms 중 큰 값을 기준으로 센다. 최대 공백 200 ms 초과 또는 큰 공백 비율 5% 초과이면 RMS 판정을 보류한다.
- 기록률은 `(표본 수 - 1) / 창의 시간 범위`, Nyquist 표시는 그 절반이다. 이는 센서 ODR이나 anti-alias 적합성을 보장하지 않는다.
- 온도 초기화 문자열·센서 오류는 다른 유효 IMU 채널을 폐기하지 않는다.
- 실시간 센서 스트림은 하나를 선택해 유지한다. 다른 센서 스트림이 동시에 들어오면 계산에서 제외하고 충돌 횟수를 표시한다. 원본 로그에는 수신 패킷을 남긴다.

## 온도

현재 유효한 온도 4개를 사용자가 기준으로 지정한다. 시작 온도 대비 상승량을 구하고 암대 간 중앙값을 뺀다.

```text
delta_T_i = temperature_i - baseline_i
relative_delta_T_i = delta_T_i - median(delta_T_1, ..., delta_T_4)
```

온도 표시는 기준 설정 전에 가능하다. 상대 상승량 비교에는 기준 설정이 필요하다. 절대 상한 감시는 유효한 온도만 있으면 가능하다. 실제 온도 측정 timestamp가 없으면 갱신 시각 미확인으로 표시한다.

## 이상 후보와 기동 처리

RMS 숫자·그래프와 온도 표시는 비행 정보가 없거나 Disarmed·기동 상태에서도 유효한 센서 데이터가 있는 동안 계속한다.

진동 이상 후보 평가에는 다음이 모두 필요하다.

1. 4개 암대 RMS 창이 유효하다.
2. 비행 상태 수신이 3초 이내이다.
3. 실제 Armed=true, 자세 roll/pitch, body 각속도가 있다.
4. 각속도 벡터 크기가 0.35 rad/s 이하이고, roll/pitch 절대값이 15도 이하이다.

이는 기동 제외용 임시 조건이다. 정상 기동을 모델링하거나 기동 영향을 보정하는 처리는 아니다. 비행 정보가 없다고 Armed를 임의로 만들지 않는다.

기본 설정은 `config.json`에서 읽는다.

| 항목 | 기본값 |
|---|---|
| RMS 창 | 2초 |
| 후보 지속시간 | 2초 |
| 상대 RMS 초과 | 0.15 m/s² |
| 상대 온도 상승 초과 | 5°C |
| 절대 온도 상한 후보 | 60°C |
| 비행 정보 유효기간 | 3초 |
| 온도 수신 유효기간 | 10초 |

상대 RMS가 임계값을 연속 초과하면 진동 후보, 온도 기준을 연속 초과하면 온도 후보, 같은 암대의 두 상태가 겹치면 복합 후보로 표시한다. 이 수치는 연구용 초기값이며 실제 정상·손상 회차로 검증되지 않았다.

## 미구현 범위

기체 운동·센서 위치의 물리 보정, 정상 기동별 예상 RMS 모델, 대역통과 필터, 검증된 임계값, 고장 원인 확정은 미구현이다. 모든 암대가 함께 상승하는 경우 상대 RMS만으로 놓칠 수 있다. 실제 모터 RPM은 출력 명령으로 대체할 수 없다.

오프라인 시간 정렬과 기준 설정은 원본·독립 비행 회차로 평가한다. 일정 줄 수로 재생하는 `--rate` 경로를 원래 비행의 검출 지연을 검증한 결과로 제시하지 않는다.
