# 실행 검증 기록

## 2026-11-05 실기체 IMU 라벨 대응

- 사용자 지정에 따라 Arm 1/2/3/4에 IMU1/3/2/4, 원본 채널 CH0/CH2/CH1/CH3를 대응했다. 온도 채널은 기존 S1/S2/S3/S4 순서를 유지했다.
- 19개 단위·통합 테스트 통과. CH1의 진동 증가가 Arm 3의 RMS·복합 이상 후보에 반영되고, 원본 로그의 CH 이름·값은 보존됨을 확인했다.
- 누락 채널의 암대 대응, 중복 매핑 거부, 이미 암대 순서인 시뮬레이션·명시적 arms 입력의 중복 교환 방지를 확인했다.
- 물리적 배선 대응은 사용자가 제공한 라벨에 근거한다. 이 검증은 실기체 배선을 직접 측정한 시험은 아니다.

## 2026-11-05 PC 수신·RMS 계산·화면 통합

환경: Windows, Python 3.12. 기존 실기체 로그와 섞이지 않도록 별도 loopback 테스트 포트 18080/18765를 사용했다.

확인한 항목:

- `python -m unittest -v test_logic.py test_server.py`: 14개 테스트 통과.
- 4개 암대에 RMS 1/2/3/4 m/s²인 합성 정현파와 서로 다른 온도를 입력해 채널별 계산값을 확인했다.
- 비행 정보와 온도 기준을 설정하지 않아도 온도·RMS·수집률이 산출되고, 진동 이상 판정만 보류됨을 확인했다.
- TCP 분할 수신, 잘못된 JSON 제외, 온도 초기화 중 유효 IMU 유지, 원본 로그·세션 ZIP 내려받기, 소스 충돌·오래된 데이터 처리 테스트 통과.
- 실제 브라우저에서 4개 암대 온도·RMS 숫자, 온도 그래프, RMS 그래프, LIVE DEMO, 가상 Arm 3 진동 증가 후보 표시를 확인했다.
- 데모 `--rate 125`는 전송 목표값이다. 브라우저에는 호스트 스케줄링을 포함한 실제 timestamp 기반 기록률이 표시됐다. 실기체 125 Hz 달성을 검증한 시험은 아니다.
- 웹 JavaScript 및 Python 소스 문법 검사 통과.
- 배포 ZIP의 필수 런타임 파일, 로그·캐시·로컬 SSH 설정 제외, 셸 스크립트 LF 줄바꿈을 확인했다.
- 테스트 송신기와 테스트 서버는 확인 후 종료했다.

실행 방법:

```bash
cd isas_portable
python3 -m unittest -v test_logic.py test_server.py
```

이번 검증의 범위에 포함되지 않은 항목:

- 실제 우분투 장치에서 실행한 네이티브 검증.
- 새 배포본과 실기체 간 실제 Wi-Fi·MAVLink 수신률·시간 동기 및 지연.
- 기체 운동 보정·기동별 정상 RMS 모델·검증된 고장 임계값.
- 실제 고장 검출률·오경보율·고장 원인 식별 성능.
